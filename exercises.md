# Flyweight Pattern Practice Exercises

This file contains **10 backend-oriented** and **10 frontend-oriented** exercises for practicing the **Flyweight Pattern**.
All examples are different from the ones we have discussed before.

---

## Backend Exercises

1. **Database Connection Pool**
   - Implement a pool of reusable database connections using the Flyweight pattern.

2. **User Permission Caching**
   - Use Flyweight to store shared user permission sets to avoid redundant memory usage.

3. **Configuration Settings**
   - Store shared immutable configuration objects for multiple services.

4. **Error Message Templates**
   - Keep shared error message templates that can be customized with parameters.

5. **Sensor Data Objects**
   - Share common sensor metadata across multiple sensor readings.

6. **Geolocation Data**
   - Reuse common location metadata for millions of GPS coordinates.

7. **API Request Headers**
   - Store reusable HTTP header configurations for API calls.

8. **Email Templates**
   - Share common email templates and customize with runtime data.

9. **Document Metadata**
   - Keep shared metadata (author, publisher) for documents in a large repository.

10. **Cacheable Query Results**
    - Store frequently accessed query results in memory as flyweights.

---

## Frontend Exercises

1. **Text Rendering in a Webpage**
   - Use Flyweight to store character glyphs for rendering large text blocks efficiently.

2. **CSS Style Reuse**
   - Store shared CSS style objects for multiple UI components.

3. **Map Rendering**
   - Store shared icon objects for rendering thousands of map markers.

4. **UI Theme Objects**
   - Share theme configurations (colors, fonts) across UI components.

5. **SVG Shape Reuse**
   - Store reusable vector shape definitions for complex graphics.

6. **Game Sprite Management**
   - Share textures for multiple game objects that use the same image.

7. **Chart Data Points**
   - Reuse visual point styles in large datasets.

8. **Form Field Validation Rules**
   - Store common validation rule objects for multiple form fields.

9. **Notification Templates**
   - Share notification message templates and populate with dynamic content.

10. **Button Component Styles**
    - Store shared button styles for consistent UI appearance.
